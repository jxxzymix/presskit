# JXXZY Official Press Kit 2026

Static artist website and printable web EPK, built from the official 15-page press-kit PDF.

## Included

- BMW M-series-inspired motorsport direction: carbon texture, cyan/deep-blue/red stripes, technical typography, and racing UI details.
- Transparent JXXZY logo opening plus a lightweight looping wallpaper derived from the supplied DXV source.
- Complete artist identity, bilingual bio, nine-genre sound map, performance DNA, live appearances, event formats, technical rider, hospitality, promoter copy, and booking brief.
- Fourteen SoundCloud track links with current artwork and eight direct YouTube set links with their thumbnails.
- Responsive navigation, reduced-motion support, lightbox, copy buttons, interactive energy journey, wallpaper pause control, and validated booking handoff to WhatsApp or email.
- Standalone `epk.html`, print-to-PDF mode, official PDF download, SEO metadata, PWA manifest, sitemap, robots, and custom 404 page.

## Local preview

Run a static server from this directory, for example:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## GitHub Pages

Push this folder to the `main` branch of `jxxzymix/presskit`. The automatic workflow in `.github/workflows/pages.yml` verifies the core payload before deployment to `https://jxxzymix.github.io/presskit/`. The second workflow is manual fallback only.
